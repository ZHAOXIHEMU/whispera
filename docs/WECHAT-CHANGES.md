# 微信酒馆本地分支 · 0.2.0

基于用户提供的 HuaDeng 完整源码，保留原 AGPL 许可及原功能代码。新增微信风格主页面；聊天内部仍使用原 ChatPage、输入工具栏、消息菜单、模型选择、思考块及回复分支等组件。原设置完整入口仍可访问。本次未发布到 GitHub。

## 会话与人物卡

- 聊天列表直接绑定会话记录，标题取 Conversation.title。头像取会话创建时的人物头像快照，预览只查询该会话最后一个消息节点当前分支，不读取整段历史。
- 同一个人物卡可产生多个会话 ID；原聊天页的新建聊天按钮继续使用。
- 会话顶部沿用独立标题及原标题编辑功能。右上角新增“•••”进入对话设置，不移除原菜单。
- 对话设置顶部显示当前原始人物卡资料，头像跳转原角色卡设置，返回后回到对话设置；下方另行编辑会话内角色名称、头像及标题。
- 名称、头像、背景和导演备注保存在已有 ConversationConfig JSON 中，无需修改数据库列结构。新会话创建时冻结；旧格式首次载入时补齐当前已知配置，无法还原历史上从未保存过的角色资料。
- 会话头像文件引用纳入配置引用检查，避免误当作无用附件清理。

## 导演备注

- “我”中的导演备注入口是全局默认，页面明确标注仅影响之后新建会话。
- 每个新会话复制总开关、条目、内容、启用状态、位置、深度、角色及频率，形成独立快照。
- 对话设置中的导演备注复用同一个 AuthorsNotePage；页面明确标注“仅当前会话”。写入经过现有 ChatService 会话锁及持久化路径。
- 请求的原导演备注转换器改用当前会话快照，再进入原来的排序、频率、深度和 Persona 兼容逻辑。全局开关不再作为已有会话的最终开关。
- 原有多选、编辑、复制、网页渲染、分享、分支、收藏、翻译、朗读、删除及消息统计代码保留。

## 聊天背景

- 默认空背景，不使用人物卡图或人物卡的背景选项。
- 对话设置 → 聊天背景 → 手机相册／预设图库／空背景。
- 手机相册复用 Comfy Mobile 的原生 MediaStore 相册选择实现，保留目录分组、搜索、置顶和大图预览；照片权限入口移至设置页。
- 内部预设图库独立于手机相册，使用上传按钮逐张导入到 App 私有目录，可在多个会话中选择。同一会话的选择独立保存。

## 此前接入内容

- 钱包从 DeepSeek 官方 `/user/balance` 读取总余额、赠送余额、充值余额、币种和可调用状态。官网说明：https://api-docs.deepseek.com/api/get-user-balance/
- 钱包下方嵌入固定 `https://platform.deepseek.com/usage`，不提供地址编辑，只有官网用量和必要的官网登录跳转可打开。API Key 不注入网页；网页需要单独登录。
- 测试 Key 未写入源码或配置。App 内由用户填写的 Key 使用原服务商配置，同时供聊天和余额查询使用。
- 朋友圈从指定的多个图片／视频文件夹读取本地素材，初始20条，北京时间00:00和12:00补齐新条目。系统后台任务可能延迟执行，恢复前台会补齐逻辑时间，不因下拉刷新额外发帖。混合最多9个且视频不超过2个，纯视频最多3个。角色来自导入的酒馆卡，无角色时空白。
- 昵称头像使用原 DisplaySetting，朋友圈、聊天及“我”共用。

## 构建与验证边界

Windows、JDK21、Gradle9.6、原工程对应 Android SDK37 工具链；目标 Android16，最低 Android13。保留原分支的 Python、原生工具和模块，因此包体积明显大于空壳版。

本机用 ASCII 路径的 Gradle 用户目录运行测试，避开测试 Worker 在中文缓存路径下启动失败的问题。Python 使用项目目录中的官方便携构建包，不需要系统安装。

测试包含会话身份和导演备注快照隔离、序列化恢复、原有导演备注注入回归、朋友圈媒体上限和时间槽、钱包网页范围。没有连接真实手机；照片授权、厂商相册分组、手势手感及官网登录仍需安装后验证。
