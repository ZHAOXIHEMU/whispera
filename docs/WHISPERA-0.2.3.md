# whispera 0.2.3 · 2026-10-29

## 朋友圈与钱包

- 封面更换的根因是固定文件路径：StateFlow 对相同路径不通知，Coil 也复用缓存。本版每次使用唯一私有文件名，保存新路径后移除旧封面，不修改源照片。
- 钱包图标从误用的文件夹图形改为钱包线框。
- 官网 WebView 使用应用级实例保留会话，不随余额更新和页面切换重新构造；载入期间遮住未完成的首帧并显示进度，启用暗色适配。余额保留上次成功结果，避免进入页面时数据区反复伸缩。
- 固定网址仍为 https://platform.deepseek.com/usage，无地址输入。增加官方根路径和必要登录跳转支持、独立Cookie、网页错误和重新加载按钮；只允许官方用量及登录范围。原API Key不注入网页，官网仍需单独登录。
- 没有真机WebView或用户官网登录状态的复现环境，不能保证官网网络/验证挑战在所有手机上可用。若站点拒绝、网络失败或跳转不受支持，现在明确显示错误，而非静默空白。

## 聊天导航迁移

- 移除聊天页整套原侧栏，包括更新卡、昵称头像、日期分组历史、角色选择栏及底部快捷按钮；不改输入工具栏和消息操作组件。
- 顶栏只显示微信式返回箭头、居中的会话名/角色与模型副标题、三点；长标题省略。返回目标为首页聊天列表。移除顶部新建、列表、通话等并列按钮。
- 三点进入微信风格“聊天信息”内页：原始卡、会话独立角色资料和标题、历史、搜索、实际请求提示词查看、AI翻译、会话导演备注、收藏、背景及语音/视频通话。密钥、应用外观、网络等全局设置集中在“我 → 设置”；原始角色参数仍通过顶部角色头像进入。
- 媒体创作、AI翻译、情侣空间、生活空间移至发现；统计在“我”。首页加号发起聊天先选择角色。原输入、思考块、回复分支、翻译/朗读/复制等消息操作继续使用原组件。

## 启动与上游内容

- 首页立即显示界面，移除等待设置读取的额外转圈屏；真实数据库升级所需的迁移保护仍保留。不承诺Android进程冷启动没有系统开销。
- 不再显示调试文字、上游公告、QQ群/微信群邀请、赞助弹窗和上游捐赠/官网入口。关于页保留开源版权和AGPL许可说明。
- 上游更新状态改为本地Idle，不查询GitHub上游、CDN或代理镜像更新源；公告加载返回空，不请求云端或使用内置广告。
- 从默认及推荐服务商列表移除“砂糖酒馆”中转，旧空Key预设按原规整逻辑清除。共享HTTP客户端阻止 rikka-ai.com（含API/赞助子域）、rikkahub.luoca.cn、ai.ota1245.top。旧有填写过的配置不抹除密钥，但不能通过此客户端请求这些地址。

## 网络审查边界

本次为源码审查及定向阻断，没有进行手机抓包，不能宣称整个应用“无外部服务器”。模型、搜索、TTS/ASR、在线翻译、媒体生成等依赖配置的第三方服务，DeepSeek钱包访问DeepSeek官方。QQ/微信机器人是可选的腾讯官方接口。Jev智能判断是可选TypeSafe服务，默认Key为空、接管开关关闭；未配置时不请求。工作区工具可能下载官方运行环境，用户导入的HTML角色卡、远程图片、插件、MCP等也可能自行联网；不能把它们当成本地离线内容。

RikkaHubAPI接口当前为空，原API基址没有实际业务方法；仍为它接入相同的网络策略，避免将来误用。赞助页路由替换为本地关于页，赞助API即使误调用也会被共享客户端阻止。

## 验证

编译和定向单元测试包含官方网页导航范围、上游域名阻断、默认中转预设清理，以及会话/导演备注隔离、导入ID和附件路径回归。未连接手机：实际手势、首次WebView渲染、官网登录及封面连续更换仍需真机确认。

## 通讯录与角色页面

- 通讯录直接展示角色，按中文拼音/英文排序并分段，右侧↑/A–Z/#索引可点按和拖动，搜索支持姓名和完整拼音。没有把原版角色列表藏到下级菜单代替改版。
- 橙色“新的朋友”入口及加号里的同名项在当前页弹出导入/新建面板，保持PNG、JSON、春水、风月、URL导入及开场白选项，继续走已有解析和世界书保存逻辑。
- 角色行可编辑，长按或点更多打开角色操作；复制（含可选记忆）、PNG/JSON导出、角色删除确认继续复用原功能。
- 原角色管理页同步改成相同通讯录样式，保留搜索和标签筛选；角色详情页改为方形头像的资料行。
- 50个现有设置/编辑页的展开大标题改为54dp紧凑居中顶栏，返回按钮换成无圆底的微信式箭头；公共分组改为平直列表与细分隔，背景与强调色统一，保留显式文字/强调色设置。没有改消息气泡、回复工具栏和提示词注入逻辑。
- 首页加号菜单以当前页为锚点和显示条件，修复HorizontalPager相邻页面同时显示同一菜单的问题。

## 聊天列表与会话操作

- 长按聊天仅有置顶/取消置顶、不显示该聊天。隐藏状态写入会话配置，重新启动仍保留；“我 → 设置 → 隐藏的聊天”可恢复，不删除历史。
- 列表时间取最后一条选中分支消息的时间，不拿修改会话标题或置顶的操作时间冒充最后消息时间：今天HH:mm、昨天、当周星期几、今年更早M月d日、往年yyyy年M月。按手机时区和周一为一周起点判断。
- 三点页明确提供“更改聊天背景”；底部红色“删除聊天”先弹确认，可取消/点空白关闭。删除保留角色卡及其他会话。
- 删除通过ChatService停止当前会话生成，再串行删除数据；与消息/标题/配置保存共用写入保护，阻止延迟回复或标题更新重新插入已删会话。
- 增加日期跨日/跨周/跨年、隐藏状态序列化与模型切换保持、删除与并发写入竞争的回归测试。
