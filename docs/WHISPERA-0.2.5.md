# whispera 0.2.5 — 2026-10-30

## 优先修复：ZIP追加导入与会话跳错
- 追加导入原来在Room写事务内调用会切换至IO线程的全文索引写入，可能争抢同一SQLite数据库写锁。改为事务内仅插入角色关联的会话/消息，提交完成后再建立索引；索引自身批量事务，避免逐条磁盘提交。
- 提交阶段使用NonCancellable，防止页面生命周期取消将数据库事务回滚而设置已经保存。处理时顶部返回隐藏，系统返回提示等待；显示解压、对话提交和索引阶段进度，节流UI更新。
- 同一应用存储中的附件优先移动，避免解压后再次复制整份大文件。保留原有UUID重映射和追加规则，不覆盖旧角色及旧会话。
- ChatVM以会话UUID显式key隔离，重新生成标题通过最新会话元数据更新，避免用旧消息快照保存标题。
- 已有数据不主动删除。本更新不声称能恢复此前版本已被物理删除的数据；需真机验证异常ZIP与中断行为。

## 性能
- 原头像即使没有加载也创建无限旋转动画；移除所有默认头像的无限动画并使用标准圆形。
- 聊天列表移除整屏离屏DstIn与haze源，顶部保留普通渐变遮罩；避免滚动时整屏纹理混合和模糊采样。
- 通讯录拼音转换/排序、会话列表配置解析移至后台；减少主标签页预组合，聊天服务延迟到操作时获取。
- 选择聊天使用轻量会话列表，不为弹窗加载全部历史消息。
- 冷启动中的插件管理构造与系统退出日志读取移至后台。保留恢复数据、必需原生库初始化，不能以编译结果承诺真机秒开或具体帧率。

## 界面与交互
- 通讯录聊天按钮：零段新建、一段直达、多段显示自适应高度的底部弹窗；支持返回、点击空白和下滑关闭。通讯录末尾显示朋友数量。
- 我页空白区域保持黑色背景，仅按钮区域使用深灰。重画底部四个图标比例。
- 视频预览全屏遮挡系统栏，默认自动播放且无控件；双击暂停/继续，单击显示或隐藏底部时间、进度及倍速设置；彻底关闭原生中部播放/跳转按钮。
- 聊天信息原角色资料压缩为单行，说明置于右侧，去掉分组小字，改8dp黑色分隔；修改头像行与其他按钮等高；新增重新生成标题。
- 语音/视频通话不是占位页：使用原ASR/AI/TTS及摄像头逻辑，需要配置服务与授权，不是微信用户之间的网络通话。未在本机实测通话服务。
